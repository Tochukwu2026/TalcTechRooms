# Project Name & Context
TalcTech Rooms; This is for an Overnight Rentals App called TalcTech Rooms.

# Tech Stack
- Frontend: [e.g., Next.js 15, TailwindCSS, TypeScript]
- Backend/Database: [e.g., Node.js, PostgreSQL, Prisma ORM]

# Build & Run Commands
- Install dependencies: `npm install`
- Run local dev server: `npm run dev`
- Run test suite: `npm test`
- Code Linter: `npm run lint`

# Coding Style & Conventions
- Use functional React components with named exports.
- Always use TypeScript strict mode types; avoid using 'any'.
- Use descriptive commits following Conventional Commits (e.g., feat:, fix:).

# Project Architecture (File Map)
- `/src/components`: Reusable UI elements.
- `/src/hooks`: Global custom React hooks.
- `/src/pages/api`: Backend serverless API routes.
